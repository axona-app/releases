# Security

## Reporting a problem

If you find a security problem in Axona, email **hello@axona.app**. Please don't open a public issue for it.

Include the Axona version, your macOS version, and the steps that show the problem. You'll get a reply as soon as possible.

## Supported versions

Only the latest release gets fixes. Axona checks for updates on launch and offers the new version.
